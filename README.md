# Amazon-Sales-Analysis-Dashboard-Power-BI
Interactive Power BI dashboard analyzing Amazon sales trends, regional performance, customer segments, and profit insights using data visualization and business intelligence techniques.

# Tools & Technologies Used
Power BI
Power Query
Data Cleaning & Transformation
Data Visualization
DAX (Data Analysis Expressions)
Excel / CSV Dataset

# Key Features
**Sales Analysis**
Sales performance by category and sub-category
Region-wise sales distribution
Segment-wise sales analysis
**Profit Insights**
Seasonal fluctuation of profit
Identification of high-performing periods
**Customer & Shipping Insights**
Sales by payment mode
Sales by ship mode
Regional performance tracking
**Interactive Dashboard**
User-friendly visuals
Dynamic filtering and drill-down analysis
Business-focused KPI visualization
**Business Insights Generated**
Identified top-performing product categories
Analyzed seasonal sales and profit trends
Compared regional sales performance
Evaluated customer purchasing behavior through payment modes
Improved understanding of shipping preferences
